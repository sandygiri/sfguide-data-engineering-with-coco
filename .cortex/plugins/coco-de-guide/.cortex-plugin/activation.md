# coco-de-guide Plugin

This plugin provides data engineering workflows, guidelines, skills, and agents for developing and testing dbt projects on Snowflake using CoCo Desktop.

## Included Components
- **Skills (`./skills`):** Custom workflow skills including `new-dbt-model` for creating and testing dbt models following project conventions.
- **Agents (`./agents`):** Subagents configured for data engineering tasks.
- **Hooks (`./hooks/hooks.json`):** Lifecycle and validation hooks for automated checks.
